# Deep learning and database projects

Coursework and projects from my MS in Electrical & Computer Engineering (Data Science & Machine Learning) at Carnegie Mellon University.

| Project | Description | Tools |
| --- | --- | --- |
| [Speech recognition](speech-recognition/) | Phoneme classification, CTC sequence model, and an attention encoder–decoder (Listen, Attend and Spell) | PyTorch, CUDA, LSTMs, Transformers, attention |
| [Face recognition](face-recognition/) | Face classification and verification with a ResNet trained with center loss | PyTorch, CNNs, mixed precision |
| [Road crash response database](road-crash-response-db/) | Triggers that assign the nearest officer and book the nearest hospital with free rooms | PostgreSQL, PL/pgSQL, earthdistance |

Notebooks run on Kaggle/Colab GPUs and need a Kaggle API key for the datasets.
